# PennantStrategy

NPBライクの球団運営ゲーム。

## 実装済

- 12球団・2リーグ・143試合のペナントレース進行
- 任意の試合数をスキップしてゲームを進行する
- DHの有無をリーグ単位で設定
- 打順、守備位置、先発ローテ、一軍枠、外国人枠の管理
- 自軍の手動運営
- スキップ中の打線・ローテ・入替設定自動化
- 順位表、チーム成績、個人成績、ランキング、選手詳細
- 試合結果、勝敗投手、セーブ、ホールド、回別スコア
- ポストシーズン、年間表彰、シーズン履歴
- オフシーズン
  - 引退
  - 戦力外
  - 戦力外獲得
  - ドラフト
  - FA市場
  - 外国人補強
  - 選手能力変化
  - 契約更新
- セーブ・ロード機能
- 開発・検証ツール
  - バランスレポート
  - 選手プローブ
  - ドラフト検証
  - headless実行用smoke/benchmark

## 主要画面

| 画面 | 役割 |
|---|---|
| ホーム | 本日の試合、直近成績、今後の試合、怪我選手、主要操作 |
| スキップ設定 | N日スキップ、自軍次戦まで、シーズン終了まで、自動セーブ、自動入替 |
| 試合結果 | 回別得点、勝敗投手、セーブ、ホールド、登板内容 |
| 順位表 | リーグ順位、勝敗、ゲーム差、チーム指標 |
| ランキング | 野手/投手の個人成績ランキング |
| シーズン履歴 | 過去年の順位、タイトル、表彰 |
| チーム詳細 | 自軍と他球団のロスター、能力、ポジション別戦力 |
| 一軍入替 | 31人枠の中で、外国人枠や投手・野手バランスを考慮 |
| 打順設定 | DHの有無に応じた打順と守備位置 |
| 起用法 | 先発ローテを6番手まで設定する |
| 選手詳細 | 能力、成績、年俸、契約、経歴 |
| オフシーズン | 引退、戦力外、ドラフト、戦力外獲得、FA、外国人、能力変化、契約更新 |
| ポストシーズン | CS・日本シリーズの進行 |
| 表彰 | MVP、新人王、各部門タイトル |
| オプション | セーブ管理、DHルール、開発用データ生成 |

開発ツールを有効にしている場合は、サイドバーに「バランスレポート」「選手プローブ」「ドラフト検証」も表示されます。

## 開発ツール

- バランスレポート: 複数シーズンを自動進行して OPS、ERA、K/9、BB/9、守備指標などを集計
- 選手プローブ: 選手能力を固定・スイープして成績変化を確認
- ドラフト検証: ドラフト候補の成長曲線や長期オートプレイを確認
- `tools/`: headless 実行用の smoke、benchmark、レポート出力ツール
