# PennantStrategy

NPBライクの球団運営ゲーム。

## 実装済

- 12球団・2リーグ・143試合のペナントレース進行(カレンダー日程・休養日つき)
- 任意の試合数をスキップしてゲームを進行する
- DHの有無をリーグ単位で設定
- 打順、守備位置、先発ローテ、リリーフ起用法(ロング/中継ぎ/セット/抑え)、一軍枠、外国人枠の管理
- 自軍の手動運営
- スキップ中の打線・ローテ・入替設定自動化
- 順位表、チーム成績、個人成績、ランキング、能力・成績一覧、選手詳細
- 試合結果(回別スコア、勝敗投手、セーブ、ホールド、打席ごとのログ、交代表)
- 選手詳細の今季試合履歴・月間成績タブ
- 投手の球種・変化球システム(球種と完成度、役割適性)
- 怪我システム(重症度ティア、部位、長期離脱の越冬持ち越し、まれな恒久能力低下)
- ポストシーズン、年間表彰、シーズン履歴(ポストシーズン成績は別集計)
- 歴代記録・タイトル履歴の一覧、選手経歴ログ(移籍・受賞・怪我などの経歴タブ)
- シーズン中トレード(交換期限あり、CPUからの提案と自軍からの提案)
- オフシーズン
  - 引退
  - 戦力外
  - ドラフト(本指名・育成ドラフト)
  - 戦力外獲得市場
  - FA市場(A/B/Cランク、金銭補償、提示年俸)
  - 外国人獲得(ポジション・選手タイプ・予算帯を指定するスカウト方式。真の能力は契約まで非公開)
  - キャンプ(特別練習: 先発/リリーフ転向、守備位置習得、コンバート、球種習得)
  - 選手能力変化
  - 契約更新(WAR・出場ベースの年俸査定)
- チーム予算(年次予算キャップ、FA・外国人・トレードなど補強のハードゲート、FA金銭補償の資金移動)
- 育成選手制度(支配下70枠外、支配下登録/育成降格、CPU自動運用)
- セーブ・ロード機能(セーブごとの独立フォルダ、試合ログ保存)
- mod対応の基盤(ルール係数、初期データ、日程、名前プールの差し替え)
- 開発・検証ツール
  - バランスレポート
  - 選手プローブ
  - ドラフト検証
  - GdUnit4による自動テスト、headless実行用レポート/ベンチマークツール

## 主要画面

| 画面 | 役割 |
|---|---|
| ホーム | 本日の試合、直近成績、今後の試合、怪我選手、主要操作。スキップボタンから7日/月末まで/自軍次戦まで/残り全試合へ派生 |
| 試合結果 | 回別得点、勝敗投手、セーブ、ホールド、登板内容 |
| 順位表 | リーグ順位、勝敗、ゲーム差、チーム指標 |
| ランキング | 野手/投手の個人成績ランキング |
| 能力・成績一覧 | 全選手の能力値・成績・高度な指標を横断表示。投手/野手/先発/中継/各守備位置で絞り込み、能力値/成績/高度な指標のタブと列ソート |
| シーズン履歴 | 過去年の順位・表彰、歴代記録、タイトル履歴 |
| トレード | シーズン中(交換期限7/31)の自軍からの提案、CPUからの提案への回答、成立トレードの一覧 |
| チーム詳細 | 自軍と他球団のロスター、能力、ポジション別戦力 |
| 一軍入替 | 31人枠の中で、外国人枠や投手・野手バランスを考慮。育成選手の支配下登録もここから |
| 打順・守備位置 | DHの有無に応じた打順と守備位置、控えをドラッグ&ドロップで設定する |
| 投手起用法 | 一軍投手一覧・先発ローテ(1〜6番手)・リリーフ起用法(ロング/中継ぎ/セット/抑え)を設定する |
| 選手詳細 | 能力、成績、今季試合履歴、月間成績、年俸、契約、経歴 |
| オフシーズン | 引退、戦力外、ドラフト、戦力外獲得、FA、外国人、キャンプ、能力変化、契約更新 |
| ポストシーズン | CS・日本シリーズの進行 |
| 表彰 | MVP、新人王、各部門タイトル |
| オプション | セーブ管理、スキップ時の自動セーブ・自動入替、DHルール、開発用データ生成 |

開発ツールを有効にしている場合は、サイドバーに「バランスレポート」「選手プローブ」「ドラフト検証」も表示されます。

## 開発ツール

- バランスレポート: 複数シーズンを自動進行して OPS、ERA、K/9、BB/9、守備指標などを集計
- 選手プローブ: 選手能力を固定・スイープして成績変化を確認
- ドラフト検証: ドラフト候補の成長曲線や長期オートプレイを確認
- `test/`: GdUnit4の自動テスト(`tools\run_tests.cmd` で実行)
- `tools/`: headless 実行用の調査・レポートツール(バランスレポート、長期オートプレイ、PAベンチマーク、球数分布、守備価値較正など)
