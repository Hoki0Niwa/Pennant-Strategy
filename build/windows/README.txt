PennantStrategy v0.1.0-alpha
================================

NPBライクの球団運営シミュレーションです。

起動方法
--------
PennantStrategy.exe を実行してください。
PennantStrategy.pck は実行ファイルと同じフォルダに置いてください。

注意
----
この版はアルファ版です。長期プレイ時のバランスや不具合を検証中のため、
重要なセーブデータはバックアップを取ってください。

ライセンス
----------
LICENSES フォルダおよび THIRD_PARTY_NOTICES.txt を参照してください。
